# Tableau Dashboards Portfolio 📊

A collection of interactive business intelligence dashboards created using Tableau. This repository showcases data visualization techniques and business insights generated from real-world datasets.

---

## Repository Contents

- `dominos_project.twbx`
  - Interactive Tableau dashboard
  - Sales Analysis
  - Order Trends
  - Performance Metrics
  - Business Insights

---

## Built With

- Tableau Desktop
- Tableau Public
- Microsoft Excel / CSV

---

## Features

- Interactive Dashboards
- KPI Monitoring
- Sales Analysis
- Order Trend Analysis
- Data Visualization
- Business Intelligence Reporting
- Filters and Drill-down Analysis

---

## Dashboard Insights

The dashboard helps analyze:

- Total Sales
- Total Orders
- Revenue Trends
- Product Performance
- Customer Ordering Patterns
- Business Performance Metrics

---

## How to View

Clone the repository:

```bash
git clone https://github.com/aakanshasaxena05/TABLEAU-DASHBOARDS.git
```

Or download the repository as a ZIP file.

Open the `dominos_project.twbx` file using:

- Tableau Desktop
- Tableau Public
- Tableau Reader

Interact with the dashboard using the available filters and controls.
